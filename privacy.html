개인정보처리방침

본 방침은 공개 조회 서비스에서의 방문자 정보 처리와 운영자 전용 기능에서의 연동 데이터 처리를 구분하여 안내합니다.

DNS를 통해 외부에 공개된 웹서비스는 학술 및 교육 목적의 조회 기능만 제공합니다. 운영자는 공개 조회 과정에서 방문자로부터 어떠한 정보도 별도로 수집하지 않습니다.

제1조공개 조회 서비스

이 안내 사이트에는 방문자 정보를 받는 입력 양식이나 회원가입 기능이 없습니다. 운영자는 이 사이트에서 방문자 추적용 쿠키, 방문 통계 수집 도구 및 광고 추적 도구를 사용하지 않습니다.

제2조호스팅 제공자의 접속 정보 처리

이 안내 사이트를 호스팅하는 GitHub Pages는 보안 목적으로 방문자의 IP 주소를 기록하고 저장합니다. 해당 기록에는 GitHub의 개인정보 처리 기준이 적용됩니다.

GitHub 개인정보처리방침

제3조운영자 전용 기능의 연동 데이터

운영자 전용 기능은 운영자가 Google 계정을 연결한 경우에만 Google Calendar 일정을 읽기 전용 권한(calendar.readonly)으로 조회합니다. 조회한 일정은 운영자 본인의 서버에 저장하며 공개 조회 서비스에 게시하거나 판매하지 않습니다.

일정 확인 기능을 제공하기 위해 운영자가 선택한 캘린더의 일정이 운영자 본인이 사용하는 AI 비서(OpenAI Codex)에 대화 맥락으로 전달될 수 있습니다.

제4조외부 계정 연결 해제

운영자는 Google 계정의 타사 앱 연결 관리에서 언제든지 연동 권한을 철회할 수 있습니다. 연결을 해제하면 Google Calendar에 대한 이후 접근이 중단되며, 운영자 서버에 이미 저장된 사본은 별도로 삭제할 수 있습니다.
